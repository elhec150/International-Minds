NEXO Web V4 — International Minds

Contenido:
- index.html: web principal de NEXO.
- network.html: NEXO Network, prototipo de red social/profesional.
- assets/: logos originales.

V4 incluye:
- Hero con movimiento sutil de avión y ruta.
- Tipografía más moderna y jerarquía visual refinada.
- Animaciones suaves y respetuosas con prefers-reduced-motion.
- NEXO Network con likes, comentarios, compartir, conectar, búsqueda, edición de perfil, creación de publicaciones y login simulado.

Todo es un prototipo frontend: no hay base de datos ni autenticación real.
